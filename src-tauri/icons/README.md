# Custom Icons
Place your custom application icons here.

To update the application icon, replace the following files with your custom graphics while keeping the exact same filenames:
- `icon.ico` (For Windows executable and taskbar)
- `icon.png` (For general usage and Linux/macOS)
- `32x32.png`
- `128x128.png`
- `256x256.png`
- `icon.icns` (For macOS)

Tauri will automatically pick up the new icons on the next build.
